# Vervi

**Vervi** es una aplicación móvil Android desarrollada en **Kotlin** que conecta prestadores de servicios emergentes con clientes locales.
La plataforma permite a los profesionales mostrar evidencia de trabajos realizados, recibir calificaciones y facilitar la contratación de talento de forma rápida, segura y confiable.

## Características

* Creación de perfiles para prestadores de servicios
* Publicación de trabajos realizados (portafolio)
* Sistema de calificaciones y reputación
* Búsqueda de profesionales por parte de clientes
* Solicitud y gestión de servicios
* Interfaz enfocada en simplicidad y accesibilidad

## Objetivo del Proyecto

Vervi busca facilitar la conexión entre personas que necesitan servicios y profesionales que desean ofrecer su trabajo, promoviendo oportunidades locales y confianza entre usuarios mediante un sistema de reputación.

## Instalación

1. Clonar el repositorio

```bash
git clone https://github.com/tu-usuario/vervi.git
```

2. Abrir el proyecto en **Android Studio**

3. Sincronizar dependencias con **Gradle**

4. Ejecutar la aplicación en un emulador o dispositivo físico

## Requisitos

* Android Studio
* JDK 17 o superior
* Android SDK actualizado
* Dispositivo o emulador Android
